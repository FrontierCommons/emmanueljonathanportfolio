# Portfolio

A simple personal portfolio built with [Astro](https://astro.build).

## Run locally

```sh
pnpm install
pnpm dev
```

Then open http://localhost:4321.

## Other commands

| Command        | Action                                  |
| -------------- | --------------------------------------- |
| `pnpm build`   | Build the production site into `dist/`  |
| `pnpm preview` | Preview the production build locally    |

## Editing content

- About: `src/components/About.astro`
- Projects: `src/components/Projects.astro` (edit the `projects` array)
- Contact: `src/components/Contact.astro` (edit the `links` array)
- Shared layout, nav and global styles: `src/layouts/Layout.astro`
